# Definición de hecho

Una tarea está terminada cuando:
- [ ] Cumple los criterios de aceptación de su historia
- [ ] Tiene tests y pasan (y e2e si toca la interfaz)
- [ ] CI en verde: build, lint y tests
- [ ] PR revisado y aprobado por otra persona del grupo
- [ ] Checklist de seguridad del PR completado
- [ ] Uso de IA declarado en el PR
- [ ] Documentación actualizada si cambia algo visible
- [ ] Desplegada en GitHub Pages desde main, y las migraciones
      nuevas aplicadas al proyecto de Supabase
